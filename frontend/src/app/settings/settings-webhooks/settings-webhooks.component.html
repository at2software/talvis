Webhooks are delivery targets. What is sent and when is defined with Sentinels, using the action "Webhook".
Every delivery is a signed JSON POST. Receivers verify it with the signing secret as described in the Standard Webhooks specification: standardwebhooks.com
  • headers: webhook-id, webhook-timestamp, webhook-signature
  • signature: v1,base64(HMAC-SHA256(base64decode(secret without "whsec_"), "id.timestamp.body"))
  • payload: {{ '{' }} id, type, timestamp, data {{ '}' }}
Failed deliveries are retried up to 8 times, from after 1 minute up to after 1 day.
